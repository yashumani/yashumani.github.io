Working paper / Applied AI architecture

AI Proposes, Deterministic Systems Decide

Where I place a model when the final result must be reproducible.

PublishedAugust 12, 2026Last reviewedAugust 13, 2026StatusWorking paper

01The boundary

I use models to interpret messy input and suggest a small number of candidates. I keep the final calculation in normal, versioned software.

02Why it matters

A model can return a plausible number without preserving the records, units, formula, or rounding behind it. A normal service can keep those inputs and run the same rule again.

03The sequence

  1. Collect the source material.
  2. Ask the model for candidates and uncertainty.
  3. Resolve the facts that could change the answer.
  4. Run the accepted inputs through versioned logic.

04What I expect from the model

I want structured candidates, evidence, missing facts, useful questions, and the model metadata used for the call. Software can validate those fields. Persuasive prose is not a reliable interface.

05Where I land

The model can reduce ambiguity. It should not hide the calculation. The final service should be able to show which inputs and rule version produced the result.
