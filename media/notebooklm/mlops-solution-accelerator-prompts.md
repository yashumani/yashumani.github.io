## Video Overview prompt

Create a polished narrated Video Overview for a technical portfolio case study. The audience is MLOps leaders, AI/ML platform leaders, data science managers, and technical recruiters.

Focus on this story:

1. The problem: manual model selection is slow, inconsistent, and hard to reproduce.
2. The solution: a config-driven Azure ML platform that automates model search, tuning, evaluation, and registration.
3. The architecture: dataset and YAML config, validation, preprocessing, baseline tournament, recipe search, Optuna HPO, holdout evaluation, Azure ML registry.
4. The proof: 457 recipes, 18 reusable components, 19 pipeline steps, 3 task families, MLflow tracking, and Azure compute execution.
5. The takeaway: model selection becomes a repeatable, tracked platform workflow instead of a manual notebook exercise.

Style requirements:

- Duration: 60 to 120 seconds.
- Visual style: clean MLOps pipeline explainer, modern diagrams, practical enterprise feel.
- Tone: credible, precise, confident, low-hype.
- Avoid: generic AI buzzwords, fake dashboards, confidential employer details, unrealistic performance claims.
- End frame: "Automated ML Pipeline Platform — reproducible model selection on Azure ML."
