What it does

Most "AI research assistant" tools take a prompt and hallucinate an answer in one shot. This platform instead treats research as a pipeline with an auditable paper trail: every claim it publishes has to trace back to a specific chunk of a specific source document, and every output passes through an automated review stage before it's considered final.

How it works

Source adapters (web, YouTube, GitHub, arXiv, X/Twitter, RSS) → extraction & parsing → evidence graph → vector index (Weaviate)

Query → hybrid retrieval + rerank → knowledge compiler → critique / repair review → published artifact

  • 13 source adapters — web pages, YouTube, X/Twitter, GitHub repos, arXiv, Crossref, Hacker News, RSS/Atom, PDFs/Office documents, images/screenshots — each with a discover → fetch → extract contract so new sources plug in without touching the core pipeline.
  • Evidence graph, not a flat vector store — source documents, extracted chunks, tables, and media are modeled as a graph of claims and concepts with explicit references, so an answer can be traced back to exactly which chunk of which document supports it.
  • Hybrid retrieval — keyword search, vector search, and a reranking pass are combined rather than relying on vector similarity alone, which materially reduces irrelevant or off-topic results.
  • Critique / repair / council loop — before an artifact is published, a separate reviewing agent checks it for unsupported claims; weak sections get automatically repaired or, for high-stakes outputs, compared across multiple independent drafts before one is accepted.
  • Durable orchestration — long-running research jobs are built on a workflow engine (Temporal) so they survive crashes and restarts instead of losing hours of work.
  • Typed programs and evaluation gates — the AI reasoning steps are written as typed, testable programs (DSPy) rather than loose prompt strings, and every change has to pass an automated evaluation suite (Promptfoo) before it ships, with full run history in MLflow.

Media direction

The public media package is structured for NotebookLM generation: a portfolio Video Overview, short vertical explainer, one-page infographic, and five-slide project deck can all be generated from the same sanitized source packet.

Engineering discipline

This wasn't built as a weekend prototype. The repository has 92 commits, 98% of them authored solo, delivered through 14 phased, evidence-gated releases — each phase required passing acceptance tests before the next could start. It's deployed on Azure Container Apps behind a VPN-gated, fail-closed security posture, with 200+ automated tests currently passing and real (metered, capped) API usage in its live runs.

Python, Temporal, Weaviate, DSPy, MLflow, Promptfoo, Azure Container Apps, Docling.
